# Git & GitHub for Linux Infrastructure

A practical collection of Git and GitHub commands, workflows, and examples used for Linux administration and infrastructure engineering.

## 👨‍💻 About This Repository

This repository demonstrates my practical knowledge of:

* Git fundamentals
* Git branching and merging
* GitHub repository management
* Pull requests and code reviews
* Merge conflict resolution
* Git-based infrastructure documentation
* Shell script version control
* Infrastructure and DevOps workflows

### 1. Git Basics

* Git installation and configuration
* `git init`
* `git clone`
* `git status`
* `git add`
* `git commit`
* `git log`
* `git diff`
* `git show`

### 2. Branching

* Creating branches
* Switching branches
* Feature branches
* Merging branches
* Deleting branches
* Remote branches

### 3. GitHub

* Creating repositories
* Clone and push
* Pull requests
* Forks
* Repository management
* Branch protection
* Issues

### 4. Merge Conflicts

Examples of:

* Identifying conflicts
* Resolving conflicts
* Testing changes
* Committing resolved changes

### 5. Linux & Infrastructure Use Cases

Git can be used to manage:

* Shell scripts
* Linux configuration templates
* Ansible playbooks
* Dockerfiles
* Kubernetes YAML files
* Terraform configuration
* Cloud infrastructure documentation
